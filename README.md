# Grama-Angana

Grama-Angana is an Android-based community management and booking application designed to simplify rural event hall booking, vaccination tracking, report generation, and user management through a user-friendly digital platform.

## Features

- User Registration and Login
- Event Hall Booking System
- Vaccination Schedule Management
- Health Record Tracking
- Event Calendar Management
- Report Generation and Sharing
- User Profile Management
- Simple and Easy-to-Use Interface

## Technologies Used

- Android Studio
- Java
- XML
- Gradle
- Capacitor

## Project Structure

- `app/` – Main Android application source code
- `android/` – Android native project files
- `assets/` – Application assets and resources
